==================================================
3. KEPLER TWO-BODY ENGINE
==================================================

Implement the relative two-body Kepler problem.

Use:

mu = M1*M2/(M1+M2)

and gravitational parameter:

mu_g = G*(M1+M2)

Implement:

A. Reduced mass

B. Kepler's third law:

T^2 = 4*pi^2*a^3 / (G*(M1+M2))

C. Semimajor axis from period:

a = [G*(M1+M2)*T^2/(4*pi^2)]^(1/3)

D. Total orbital energy:

E = -G*M1*M2/(2*a)

Equivalent reduced-mass formulation must be handled consistently.

E must represent the TOTAL relative orbital mechanical energy.

E. Orbital velocity for a circular orbit:

v = sqrt(G*(M1+M2)/a)

F. Vis-viva equation:

v^2 = G*(M1+M2)*(2/r - 1/a)

G. Orbital angular momentum:

L = mu * sqrt(G*(M1+M2)*a*(1-e^2))

H. Specific angular momentum:

h_specific = sqrt(G*(M1+M2)*a*(1-e^2))

I. Periapsis:

r_p = a*(1-e)

J. Apoapsis:

r_a = a*(1+e)

K. Mean motion:

n_mean = sqrt(G*(M1+M2)/a^3)

L. Orbital period from mean motion:

T = 2*pi/n_mean

==================================================
4. KEPLER CONSISTENCY CHECKS
==================================================

Create a consistency validator.

Given enough orbital parameters, verify that:

- period and semimajor axis satisfy Kepler's third law
- energy agrees with semimajor axis
- angular momentum agrees with a and e
- periapsis/apoapsis are physically valid
- eccentricity satisfies:

0 <= e < 1

for bound elliptical orbits.

The validator must return structured results such as:

{
    "passed": true,
    "checks": [...],
    "relative_errors": {...}
}

Never silently accept invalid physics.

==================================================
5. HYDROGEN ENGINE
==================================================

Implement the non-relativistic hydrogen atom.

Hamiltonian:

H = -hbar^2/(2*mu) * laplacian
    - e^2/(4*pi*epsilon_0*r)

Use reduced electron-proton mass:

mu = me*mp/(me+mp)

Implement the analytical bound-state energy:

E_n = -mu*k^2/(2*hbar^2*n^2)

where:

k = e^2/(4*pi*epsilon_0)

Also provide the familiar approximate representation:

E_n ≈ -13.6 eV / n^2

but calculate using physical constants internally.

Implement:

energy(n)

energy_ratio(n1, n2)

binding_energy(n)

Bohr radius using the reduced mass:

a0 = hbar^2/(mu*k)

and the characteristic radius:

a_n = n^2*a0

Be explicit that these are hydrogen quantum-state relationships, not classical electron orbits.

==================================================
8. KEPLER ↔ HYDROGEN MATHEMATICAL CORRESPONDENCE
==================================================

Implement the known analytical correspondence carefully.

For a general attractive inverse-square potential:

V(r) = -k/r

define:

Lambda = sqrt(mu*k*a)

For the Coulomb/Kepler problem, implement the action relation:

Lambda = J_r + L

For semiclassical quantization use the Langer-corrected form:

J_r = (n_r + 1/2)*hbar

L = (l + 1/2)*hbar

Therefore:

Lambda = (n_r + l + 1)*hbar

Define:

n = n_r + l + 1

Then derive:

a_n = n^2*hbar^2/(mu*k)

and:

E_n = -mu*k^2/(2*hbar^2*n^2)

IMPORTANT:

Clearly mark this as the KNOWN KEPLER-COULOMB / HYDROGEN CORRESPONDENCE.

It is NOT a newly discovered relationship.

Do not imply that planetary systems are quantum systems.

==================================================
11. EFFECTIVE N
==================================================

Implement an explicitly named quantity:

n_eff

IMPORTANT:

n_eff is NOT automatically considered the hydrogen quantum number.

For a reference semimajor axis:

n_eff = sqrt(a/a_ref)

Also support equivalent period scaling:

n_eff = (T/T_ref)^(1/3)

and energy scaling:

n_eff = sqrt(E_ref/E)

when both energies are negative bound-state energies and the ratio is handled correctly.

The implementation must label this as:

"dimensionless effective index"

NOT:

"quantum number"

Provide a comparison function that checks whether multiple definitions of n_eff agree.
